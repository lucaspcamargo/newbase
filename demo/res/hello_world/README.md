A minimal scene that sets up a camera, shows a sprite, and runs a Lua script.
Good starting point for understanding how entities, components, and systems fit together.

At any point during this demo, you may press **`F1`** to bring up the editor tools.
This will allow you to inspect the scene, view and edit entity/component data, inspect resources, and more.

You can also bring out the console with the **tilde (`)** key, which will show log messages.
