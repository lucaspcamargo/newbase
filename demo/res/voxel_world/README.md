A demo for the `voxel_world` system, and of shadow map cascades.

`voxel_world` integrates the `stb_voxel_render` library for mesh generation. The internal voxel and chunk data structures and generation are engine-native. The system is still quite limited, but enough for this demo.

The main driver for bringing in this system was generating interesting geometry for demonstrating CSM. Concevably we could use for other things too.
