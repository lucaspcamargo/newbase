This is our first 3D rendering testbed.

We present a PBR-shaded glTF 2.0 model, lit using IBL techniques. There are no analytic lights in ths demo.

The backgound uses the prefiltered specular cubemap.

You can use the arrow keys, or joystick analog, to rotate the model.
