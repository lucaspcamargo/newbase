A classic Asteroids clone built on top of newbase.
Showcases physics, particle systems, sprites, audio, Lua scripting, and scene management all working together.

Use **arrow keys** (or joystick analog) to control the ship, and press **`A`** (joypad X) to fire.

Press **`F1`** to bring up the editor tools to inspect the scene and entity components.
